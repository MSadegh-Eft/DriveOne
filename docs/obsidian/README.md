# DriveOne code-learning vault

Open this folder as an Obsidian vault and start with [[Home]]. The notes use short sentences and define technical terms when they first appear. They keep the implementation detail, but put the reason for each file before the details.

Use [[Development Roadmap]] when you are unsure what to read next. Use [[Repository Map]] when you want to find a file. Use the code walkthroughs beside the real source; the notes explain the source but do not replace it.

When code changes, update the matching walkthrough, [[Current Status and Next Steps]], and [[Decision Log]]. Record what was measured, not only what was intended.
